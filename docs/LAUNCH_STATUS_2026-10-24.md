- CI 浏览器测试改用生产构建的 `next start`。
- 生产预检拒绝无效 API 地址、API 与后端域名不一致、URL 多余路径/查询/凭据、跨域部署缺少网站 origin，以及 Auth0 domain 误填协议或路径。
