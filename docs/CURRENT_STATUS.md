# 项目现状

整理：2026-10-31。依据当前源码、Git 历史和截至 2026-10-28 的交接及验收记录；本轮没有重新执行线上业务验收。

DubbingNow 是面向清晰单人音视频的跨语言配音网站。站点已部署，正式域名完整业务链路仍待验收。

## 已实现

- Next.js 16.4.3 / React 19.3 / TypeScript / Tailwind；首页、四类工具页、12 种目标语言落地页、博客、定价及基础信息页，包含 SEO metadata、sitemap 和结构化数据。
- 浏览器提取音频、直传、进度、预览和视频合并；原视频保留在用户设备。
- Google Gemini 识别翻译与预设音色；Fish inline 根据本次任务参考音克隆，FFmpeg 按时间线对齐。
- Auth0 登录注册、Turnstile 游客验证、用户积分和流水、任务历史、管理员策略；预留、结算及失败退款。
- 生产架构为 Vercel 网页 / API / Queues，加 Cloudflare D1 数据库和私有 R2 音频；本地保留 SQLite 和独立 worker。

现有记录已通过真实 Google / Fish / D1 / R2 短样、本机真实 Auth0 账户配音与积分闭环。正式域名和 HTTPS 最近有 10 月 28 日复查记录。源码最近提交为 `3a0a533`，当前分支 `codex/cloudflare-storage`。生产使用 CLI 发布，尚未接通 GitHub 自动部署。
